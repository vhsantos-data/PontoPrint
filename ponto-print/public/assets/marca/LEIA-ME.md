# Arquivos da marca

Coloque aqui os arquivos oficiais do logo da Ponto Print.

Preferência, do melhor para o aceitável:

1. **SVG** — vetor, nítido em qualquer tamanho, poucos KB. É o ideal para web.
2. **AI ou PDF vetorial** — eu converto para SVG.
3. **PNG com fundo transparente**, o maior que existir.

Nomes sugeridos (não precisa ser exato, eu renomeio):

- `logo-horizontal.svg` — o logotipo "Ponto Print" deitado
- `monograma.svg` — o "PP" quadrado
- variações que existirem: versão só preta, versão negativa (para fundo escuro) etc.

⚠️ **Esta pasta fica dentro de `public/`, ou seja, tudo aqui vai para o ar**
quando o site for publicado. Não coloque arquivos internos.
